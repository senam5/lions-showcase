# Lions Showcase registration

Registration page for the Lions St-Lawrence men's D2 basketball Showcase
(Sat Nov 28, 2026, 16:30-18:30, Cégep Champlain St-Lawrence).

- Page: `index.html` (English first, French under it). Styles: `lions.css`.
- Sign-ups go to a Google Apps Script web app (URL in `index.html`, `ENDPOINT`),
  which writes them to a private Google Sheet. The script's source lives in the
  Lions-workout repo (`APPS-SCRIPT-SHOWCASE.gs`).
- Published with GitHub Pages from `main`.
